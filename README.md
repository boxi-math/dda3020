# DDA3020 Machine Learning study course

Website: https://boxi-math.github.io/dda3020/

Interactive study materials for lectures 09–11: Neural Networks, CNN, and RNN / Transformer. Includes 12 chapters, 27 worked exercises, numerical labs, and 9 narrated video parts (about 77 minutes) with English and Chinese subtitles.

Based on Prof. Jicong Fan’s supplied 2025 CUHK-Shenzhen lecture slides. This is a companion study resource, not the new semester’s official course site. Original lecture material and diagrams are credited to their respective authors. Original slide PDFs and production caches are not included.

This repository contains the built website. GitHub Pages serves the main branch from the repository root.
